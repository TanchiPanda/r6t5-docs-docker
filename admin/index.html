积分帮助（开发提示）

1) 账户与积分都放在你在「文档积分」里填的 Supabase 项目中，前端只用 anon key + 用户 JWT。 2) 注册即由触发器自动开积分账户（余额 0）；VIP 到期只影响解锁，不影响账户。 3) 积分入账方式（本系统不提供人民币充值/提现）： · 兑换码：后台「兑换码」批量生成，读者在账户面板兑换； · 手工加分：Supabase SQL 执行 select public.r6t5_grant('用户UUID'::uuid, 100)； · 接支付：支付回调验签后调用 r6t5_grant / r6t5_activate_vip 即可，建议在自建后端做，不要放前端。 4) 安全：service_role key 只放服务端环境变量 SUPABASE_SERVICE_KEY，前端永远拿不到； r6t5_accounts / r6t5_unlocks / r6t5_vip_orders 均已启用 RLS，只允许本人读取。 5) 计价：文档树单篇价格为准，0 或留空免费；可读比例 100% 时全站免费。
